# 字数统计

侧栏面板显示**当前笔记**的字数、西文词数、非空行数和粗略阅读时间。保存后（自动保存大约 800ms）面板会更新。「字」的算法和状态栏一致：去掉空白后的码点个数。

命令面板：

| 命令             | 快捷键           |
| ---------------- | ---------------- |
| 统计当前笔记字数 | `Ctrl/Cmd+Alt+W` |
| 复制字数统计     |                  |

复制出去的是一行纯文本，例如 `欢迎 · 128 字 · 4 词 · 约 1 分钟`。没有打开笔记时不会写剪贴板。

preview v1 的沙箱拿不到未保存的编辑器正文。面板读的是已保存内容；宿主如果实现了 `editor.getContent()`，会优先用它。

## 装进笔记库

```bash
pnpm --filter @ai-notes/plugin-word-count build
```

把这个目录复制到 `<vault>/.ainotes/plugins/word-count/`（目录名必须等于清单里的 `id`）。重新打开库，在插件设置里启用。右侧会出现「字数」标签，里面是插件自己的 iframe。

阅读时间：汉字（以及假名、谚文）按每分钟 400 字，西文词按每分钟 220 词，加总后四舍五入，有内容时至少 1 分钟。
