# 每日笔记

按你电脑的本地日期，在 `日记/YYYY-MM-DD.md` 放一篇笔记。文件不存在时才创建，已有的内容不会被盖掉。父文件夹会随写入一起出现。

正文是一份短模板：计划、记录、回顾，以及指向昨天的双链。侧栏「今日」列出最近 7 篇，并摘录今天这篇的开头。

| 命令             | 快捷键           |
| ---------------- | ---------------- |
| 创建今日笔记     | `Ctrl/Cmd+Alt+D` |
| 复制今日笔记链接 |                  |

复制出去的是 `[[日记/2026-11-10.md]]` 这种双链。preview v1 没有「打开某篇笔记」的 API，所以插件不会替你切换编辑器。复制链接之后，用快速切换（`Ctrl/Cmd+O`）输入日期即可打开。

## 装进笔记库

```bash
pnpm --filter @ai-notes/plugin-daily-notes build
```

把这个目录复制到 `<vault>/.ainotes/plugins/daily-notes/`，重新打开库并在插件设置里启用。示例库是内存里的，关掉页面后这些文件就没了；要留住日记，请打开一个真实文件夹。
