# 记忆卡片

卡片是笔记库里的普通 Markdown，不是只存在索引里的隐藏状态。删掉 `.ainotes/index.db` 之后，卡片会和其他笔记一起被重新索引。

## 文件

目录固定为 `记忆/`。一张卡片一个文件，路径一般是 `记忆/<id>.md`。

```markdown
---
type: card
id: weekly-layout
title: 这周完成了哪三件事？
kind: qa
origin: handwritten
source: 日常/周报.md
sourceStart: 120
sourceEnd: 240
ease: 2.5
interval: 0
repetitions: 0
due: 2026-11-10
lapses: 0
---

## 问题

这周完成了哪三件事？

## 答案

搭好三栏布局；打开本地文件夹作为 Vault；编辑器改的是 Markdown 原文。

来源：[[日常/周报.md]]
```

| 字段                                   | 含义                                                                        |
| -------------------------------------- | --------------------------------------------------------------------------- |
| `kind`                                 | `qa` 问答，或 `cloze` 挖空。挖空题干里保留 `{{答案}}`                       |
| `origin`                               | `generated` 模型生成，`handwritten` 从笔记语法收集，`manual` 在对话框里手写 |
| `source` / `sourceStart` / `sourceEnd` | 来源笔记和字符偏移。复习时可以跳回去                                        |
| `ease`                                 | SM-2 难度系数，初始 `2.5`，最低 `1.3`                                       |
| `interval`                             | 距离下次复习的天数。`0` 表示今天还要复习                                    |
| `repetitions`                          | 自上次忘记以来连续记住的次数                                                |
| `due`                                  | 下次复习日，`YYYY-MM-DD`                                                    |
| `lapses`                               | 答成「忘记」的次数                                                          |

正文会进入全文索引和混合检索，所以问答引用里可以出现卡片。`来源` 那一行是双链，来源笔记的反向链接里也能看到这张卡。

## 手写语法

写在任意笔记里，不要写在 `记忆/` 下面。打开库、保存该笔记，或运行命令「收集手写卡片」时收进 `记忆/`。

三种写法可以混用。代码块里的内容不会被收成卡片，除非那个代码块的语言是 `card`。

单行问答，用两个冒号分开：

```markdown
间隔重复算法::SM-2。第一次记住隔 1 天，第二次隔 6 天。
```

挖空，一对花括号包住要藏起来的词。同一段里可以有多处，答案用顿号接在一起：

```markdown
本地索引可以随时{{重建}}。
```

问答块，问题和答案都可以换行。写上 `id` 之后，改问题或答案都会更新同一张卡，复习进度还在：

````markdown
```card
id: weekly-layout
Q: 这周完成了哪三件事？
A: 搭好三栏布局；打开本地文件夹作为 Vault。
```
````

没有 `id` 的单行问答和挖空，用题干生成稳定 id。只改答案时进度还在；改了题干会当成一张新卡。

## 生成

命令面板：

- 从当前笔记生成卡片
- 从选中文本生成卡片
- 新建记忆卡片
- 收集手写卡片
- 开始复习

生成会走已经配置好的模型路由，请它只根据给出的文字输出 JSON 数组。结果先出现在预览里，可以改问题、改答案、换问答或挖空、删掉不要的，再保存。没点保存就不会写文件。

## 复习

算法是 SM-2 的四档评分。难度系数用 SuperMemo 2 的公式更新，并且不低于 1.3。间隔按复习前的难度系数计算，单位是整天：

| 评分 | 质量 | 第一次记住                             | 之后                                      |
| ---- | ---- | -------------------------------------- | ----------------------------------------- |
| 忘记 | 1    | 今天再来，连续次数清零，并记一次 lapse | 同左                                      |
| 困难 | 3    | 1 天                                   | `round(间隔 × 1.2)`，至少 1 天            |
| 记得 | 4    | 3 天                                   | `round(间隔 × 难度系数)`，至少 1 天       |
| 简单 | 5    | 7 天                                   | `round(间隔 × 难度系数 × 1.3)`，至少 1 天 |

顶栏「复习」上的数字是今天到期的张数，含还没复习过的新卡。复习时按空格翻面，`1` 到 `4` 打分。队列里还有别的卡时，「忘记」会把这张卡放到今天队列的末尾。

## 来源笔记改名或删除

改名或移动来源笔记（以及它所在的文件夹）时，卡片 frontmatter 里的 `source` 和正文里的双链会跟着改到新路径，复习进度不动。

删除来源笔记时不删卡片。复习页会写「来源笔记已不在库里」，打分仍然有效。如果以后用同一个路径把笔记加回来，链接会重新对上。

删掉 `记忆/` 或某一张卡的文件，就是删掉这张卡。

## 没配模型

手写语法、收集、新建和复习都不需要模型。只有「生成卡片」会检查当前对话模型：OpenAI 兼容接口要有地址、模型名和 API Key，Ollama 要有地址和模型名。没配好时按钮会说明原因，并可以打开模型设置。嵌入模型仍然只影响混合检索；不填嵌入模型时，卡片照样进全文搜索。
