# 少数派 Matrix 投稿提纲

这是给编辑看的提纲，不是发布日贴出去的短文。少数派的稿子通常要先过编辑，发布时间不由你定。建议在对外发帖之前就投，不要跟 Show HN 挤在同一个小时。

语气按少数派的习惯：先讲读者的文件在哪，再讲模型，主动把没做的事情写出来。不用「革命性」「颠覆」「开箱即用的 AI 笔记」这种句子。文中不要出现仓库里没有的数字。

`docs/architecture.md` 里的图谱、同步、划词改写、托管额度，是后面的打算。正文里放到「还没有」一节，不要写成已经能用。

## 标题备选

推荐第 2 个。它把局限放进标题，编辑和读者都知道这不是完成品。

1. 把笔记留在文件夹里，再让模型按这些笔记回答
2. 一个接 Ollama 的本地笔记：引用、记忆卡片，以及这一版还没做的事
3. 本地 Markdown 笔记怎么接上自己的模型

## 读者

已经在用 Obsidian、纯文件夹，或者本机 Ollama 的人。他们在意文件能不能被别的程序打开，密钥放在哪，以及断网时还剩什么。不是在找一个新的聊天网站。

## 导语（三句，可直接改）

笔记是一个文件夹里的 Markdown。提问时，程序把当前笔记和检索到的片段交给你自己的模型，回答里的路径可以点回原文。模型可以是本机已经跑着的 Ollama，也可以是你自己的 API Key；桌面端把这把密钥放进系统钥匙串，不放进笔记库。

## 结构

### 1. 文件在哪

写清楚：一篇笔记一个 `.md`，索引在 `<vault>/.ainotes/`，删掉可以重建。没有账号，没有同步。要多设备就自己拷文件夹，或用已有的 git / 网盘。

不要写「数据绝对不会离开这台电脑」。云端模型会收到你提交给它的笔记片段。插件只有在你授予 `network`、并且域名写在清单里时，才由宿主代发请求。v0.1.0 没有遥测客户端，这句可以写，不要扩写成一份隐私政策。

配图：`docs/assets/sample-vault.png`，示例库的三栏。图注写明这是浏览器预览里的内存示例库，界面是中文。

### 2. 问答实际做了什么

右侧叫「问答」，不是一个单独的品牌功能。带上当前笔记和检索到的片段，回答流式输出。`[[路径]]` 可以点开。模型没有写引用时，结束之后仍列出检索到的笔记。

搜索：不填嵌入模型就只有全文（SQLite FTS5）。桌面端填了嵌入模型才用 sqlite-vec。浏览器预览不会因为你填了一个名字就变成向量搜索。不要写召回率。

配图：动图 `docs/assets/demo.gif`，或保留 mp4 链接。图注按 README：打开示例库、写双链、搜索、看带引用的回答。不要把示例库里那条回答说成固定文案或官方评测。

### 3. 接上本机 Ollama

只在第一次、而且尚未保存模型设置时探测 `http://127.0.0.1:11434` 的 `GET /api/tags`。选一个已安装的聊天模型，优先 llama3.2、llama3.1 或 Qwen 这一类，不用嵌入模型冒充聊天模型。装了 `nomic-embed-text` 只做建议，字段留空。不会执行 `ollama pull`。

浏览器预览需要 `OLLAMA_ORIGINS`（`http://localhost:1420`）。安装包里的页面来源是 `http://tauri.localhost`。云端是同一个设置框里的 OpenAI 兼容接口。密钥：桌面端进钥匙串，浏览器预览进 `localStorage`。

这一节用一张设置说明就够了，不必截一张填着真 Key 的图。

### 4. 卡片和插件，点到为止

卡片是 `记忆/` 里的 Markdown，算法是 SM-2。手写语法是 `问题::答案`、`{{挖空}}`、`card` 代码块。生成卡片可选，要先配好模型。手写、收集、复习不需要模型。四档评分和间隔以 `docs/cards.md` 为准，不要在正文里改数字。

配图：`docs/assets/review.png`。

插件：iframe，没有 `allow-same-origin`，六项权限，API 是 preview v1。例子是 hello-notes、word-count、daily-notes。不要写成插件市场已经开了。

配图：`docs/assets/links.png` 或 `docs/assets/commands.png`，二选一，说明反链或命令面板即可。

### 5. 这一版没有的东西

单独成节，用表格或短列表：

- 没有图谱、移动端、同步、插件市场、编辑器里的划词改写
- `apps/web` 和 `server` 是占位
- 安装包默认未签名。macOS 在没有 Apple 证书时是 ad-hoc 签名且没有公证，可能提示已损坏。Windows 没有 Authenticode 时 SmartScreen 会拦截。命令和点击见 README。不要建议关掉 Gatekeeper 或 SmartScreen
- 没有自动更新
- 界面是中文

和 Obsidian、Logseq 的对照直接指向 README 里的表，并写明那是「各自围绕什么来做」，不是排行。不要加一句「更适合谁」的结论，除非你只用表里已经有的行来说明。

## 结尾

给仓库链接，MIT，以及源码预览的三行命令（Node.js 26.13.0，pnpm 12.16.1，`pnpm --filter @ai-notes/desktop exec vite`，然后打开 `http://localhost:1420`）。请读者反馈引用是否真的能回到笔记，而不是征求功能投票。

## 投稿前再对一遍

- 没有用户数、下载量、速度、准确率
- 没有「完全离线」这种一刀切。Ollama 那条路径不需要把笔记发到云上；云端 Key 那条路径会把片段发给你填的地址
- 没有把示例库的某句回答当成产品承诺
- 密钥没有写进任何截图
